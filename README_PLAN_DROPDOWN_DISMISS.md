# Juntos Fit — Plan Dropdown Dismiss Polish

Install this after the Plan Tab polish patch.

Behavior:
- Tap/click `Deb’s Current Plan` to open.
- Tap/click it again to close.
- Tap/click anywhere outside the selector to close.
- Press Escape on desktop/web to close.
- Uses pointer events so the outside-tap behavior is the same on mobile and desktop.

No SQL migration is required.

Extract into:
C:\FitnessCoach\App

Then run:
npm run build
npm run dev
